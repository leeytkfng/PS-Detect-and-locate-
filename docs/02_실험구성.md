# 2. 실험 구성

## 7단계 파이프라인
```
[1] 오디오 16kHz
[2] 프레이밍 25ms 윈도우 / 10ms hop (n_fft=512, Hann)
[3] DSP 특징 추출 (프레임별)  —  magnitude · phase · discontinuity
[4] 윈도우 풀링 0.16s (mean+std+max)  —  세그먼트 라벨과 1:1 정렬
[5] 경량 분류기 (LightGBM, 윈도우 단위)
[6] 윈도우 P(가짜)  —  탐지 = max 풀링 / 국소화 = 시퀀스
[7] 후처리(median/gaussian 평활) + 평가(Utterance EER / Range-EER)
```

## 디렉토리 구조 (단계별)
```
step1_data/        ps_data.py            [1] 데이터 접근 + 라벨 검증
step2_features/    features.py           [2][3] 프레이밍 + DSP 특징 (+ augment.py)
step3_dataset/     pipeline.py           [4] 윈도우 풀링 + 데이터셋
                   build_full.py             전체 split 병렬 특징추출
step4_model/       model.py              [5][6] 분류기(6종) + 풀링/평활
step5_evaluate/    evaluate.py           [7] Utterance EER / Range-EER
step6_run/         run.py, run_full.py       실행(내부분할 / 정식 프로토콜)
step7_analysis/    analyze_ratio · compare_methods · seam_detect ·
                   postproc_localize · run_augment · diag_augment ·
                   run_cqcc_full · run_mgd_seam · verify_fusion · (탐색·그림)
tools/             make_report.py            PDF 보고서 생성기
figures/ results/ report/ docs/             산출물·문서
```
각 모듈은 형제 `step*/`·`tools/` 디렉토리를 `sys.path`에 자동 추가 → 어디서든 실행 가능.

## 환경 / 의존성
- Python 3.10, 코어 128 / RAM 503GB / GPU H200 (단, 본 파이프라인은 **CPU 기반**)
- 핵심 패키지: `numpy, scipy, soundfile, librosa, scikit-learn, lightgbm,
  xgboost, matplotlib, fpdf2, praat-parselmouth(F0), pyannote.metrics(Range-EER)`
- 데이터: PartialSpoof v1.2 (Zenodo record 5766198), `partialspoof/` 클론에 다운로드
  (대용량이라 git 제외, 환경변수 `PS_DATA`로 경로 지정).

## 실행 예
```bash
pip install -r requirements.txt
python3 step3_dataset/build_full.py train      # 전체 특징추출 + 캐시(멀티프로세싱)
python3 step3_dataset/build_full.py dev
python3 step6_run/run_full.py --test dev  --backend lgbm   # 정식 train→dev
python3 step6_run/run_full.py --test eval --backend lgbm   # 정식 train→eval
python3 step6_run/run.py --backend lgbm                    # dev 내부분할(빠른 비교)
```
