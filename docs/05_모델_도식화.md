# 5. 모델 도식화

## 전체 흐름
```
                     ┌──────────────── step2_features ───────────────┐
 audio 16kHz ──▶ framing(25/10ms) ──▶ DSP features (per frame)
                                       · magnitude (STFT 771, LFCC 180)
                                       · phase (IFD+flux 96)
                                       · disc (flux+log-energy d1/d2 54)
                                              │
                          step3_dataset ──▶ window pooling 0.16s (mean+std+max)
                                              │  (세그먼트 라벨과 1:1 정렬, full=1101-d)
                                              ▼
                          step4_model ──▶ LightGBM  ──▶ window P(spoof)
                                              │
                    ┌─────────────────────────┴─────────────────────────┐
            탐지(detection)                                   국소화(localization)
       score = maxₜ P(spoof)                          P(spoof) 시퀀스 → 평활(gaussian)
       → Utterance EER                                 → 구간(range) → Range-EER
```

## 분류기 (step4_model/model.py)
- **주모델: LightGBM** (gradient boosting)
  ```
  LGBMClassifier(n_estimators=300, learning_rate=0.05, num_leaves=63,
                 class_weight="balanced", subsample=0.8, colsample_bytree=0.8)
  ```
- 비교 백엔드: `logreg`(선형), `rf`(배깅), `mlp`(얕은 신경망), `xgb`, `histgb`.
- 윈도우 라벨은 거의 균형(spoof≈0.5)이라 class_weight 영향은 작음.

## 출력 사용 방식
- **탐지** = 발화 점수 = `maxₜ P(spoof)` (max 풀링). 가짜 윈도우 하나라도 있으면 spoof.
- **국소화** = 윈도우 P(가짜) 시퀀스 그대로 → 시간 구간.
- **후처리** = 발화별 점수에 median/gaussian 평활 (in-domain Range-EER 개선).

## 학습/평가 프로토콜
- **dev 내부분할**: dev에서 70/30(발화 단위 GroupShuffleSplit). 낙관적.
- **정식 train→dev / train→eval**: train으로 학습 → dev/eval 평가. 신뢰 수치.
- 분할은 항상 **발화 단위**(프레임 누수 없음). 화자 누수 별도 통제(8장 참조).
