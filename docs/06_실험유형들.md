# 6. 실험 유형들

## 평가 지표
- **Utterance EER**(탐지): 발화 점수 = maxₜ P(spoof), FAR=FRR 지점의 오류율.
- **Range-EER**(국소화): 공식 `metric/RangeEER.py`와 동일 라이브러리(pyannote
  DetectionCostFunction)·로직 재현. 예측·정답을 구간(range)으로 보고 임계값 스윕 →
  FAR=FNR. point/segment EER과 달리 측정 해상도에 robust. 정답 = 0.02s 라벨.

## 프로토콜 (3종)
| 프로토콜 | 학습 → 평가 | 성격 |
|---|---|---|
| dev 내부분할 | dev 70/30 | 낙관(같은 분포) |
| train→dev | train → dev 전체 | 정식·in-domain |
| train→eval | train → eval 전체 | 정식·**unseen 공격**(최종) |

## 데이터 사용
- 초기 탐색: dev 1,500 샘플(빠른 비교).
- 정식 평가: train/dev/eval **전체** 특징추출(`build_full.py`, 멀티프로세싱) 후 학습/평가.
