# 3. 실험 데이터

## 데이터셋: PartialSpoof v1.2
- ASVspoof2019 LA(진본 + 합성 TTS/VC)를 **재료**로 구축한 부분 위조 데이터셋.
- 전체(train/dev/eval) **모두 사용**.

| split | 발화 수 | 윈도우 수(0.16s) | 가짜 윈도우 비율 |
|---|---:|---:|---:|
| train | 25,380 | 558,407 | 0.543 |
| dev   | 24,844 | 560,279 | 0.538 |
| eval  | 71,237 | 1,558,425 | 0.497 |

- dev 구성: 진짜 2,548(`LA_D_*`) + 가짜 22,296(`CON_D_*`).
- 네 출처(con_wav / dev.lst / protocol / segment_labels) 개수 **완전 일치** 검증.

## 제작 방식 (= 곧 단서)
1. 볼륨 **−26 dBov 정규화** (음량 차이로 들통나는 것 방지).
2. **VAD 3종 다수결**로 교체 후보 구간 선정.
3. 같은 화자의 다른 발화에서 비슷한 길이 구간 선택.
4. **교차상관(cross-correlation)으로 최적 연결점**을 찾고 **overlap-add**로 이어붙임.
5. 라벨링: TTS/VC 프레임 = spoof, 진본 프레임 = bonafide.

→ **화자·음량 단서는 무력화**(같은 화자 + 음량 정규화), **이음새 + 보코더 아티팩트가
진짜 단서**로 남는다. 이것이 특징 설계의 근거다.

## 라벨 형식
- `segment_labels/<split>_seglab_<res>.npy` : 0-d numpy → `dict{발화id: 프레임별 '0'/'1'}`.
- 규약: **1 = bonafide(진짜), 0 = spoof(가짜)**.
- **6+1개 해상도**(0.01 ~ 0.64초)별 파일. 프레임 수 = ceil(길이 / 해상도).
- 본 연구: 모델 윈도우 = **0.16s**, Range-EER 정답 = 더 고운 **0.02s**.

## seen / unseen 분할 (일반화 시험대)
- **train · dev = 본 공격(A01–A06)** : in-domain.
- **eval = 미학습 공격(A07–A19)** : unseen attack → 일반화 평가.
- 출처: ASVspoof2019 LA. eval은 train에 없던 TTS/VC 시스템으로 구성돼 일반화 한계를
  측정할 수 있다.

## 조작 비율(intra-spoof ratio)
- 발화 내부 생성 구간 비율을 10단계로 양자화해 다양하게 샘플링.
- → "가짜가 짧을수록 어렵다"는 분석(7장)의 기반.
